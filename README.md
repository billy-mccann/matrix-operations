Matrix Operations was created to provide myself with some "from-scratch" (i.e. - no numpy, pytorch, pandas, etc) utilities for implementing "from-scratch" ML algorithms. The idea here is simply to see how many ML algorithms can be implemented before the exclusion of third party libraries becomes intolerable. 

Currently it provides utilities for:
- Reduced Row Echelon Form (RREF) computation
- Matrix inversion
- Matrix multiplication
